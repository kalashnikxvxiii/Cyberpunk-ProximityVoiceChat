# Changelog

Every release's section is its GitHub Release notes and its Nexus changelog (`tools/package.sh`). Add a
`## <version>` section before tagging `v<version>`.

## 0.2.0

- First public release: proximity voice for NightCoop co-op, voice over NightCoop's SDK (nothing to set up).
- Walls, doors and openings, room reverb, optional realistic acoustics with Valve's Steam Audio.
- Shouting carries further, game noise covers distant voices.
- Party radio at any distance, lobby chat.
- Echo cancellation and noise suppression (classic or AI/RNNoise), push-to-talk or open mic.
- End-to-end encrypted voice; manual mode with an optional relay server and random room codes.
- Guided setup, CET menu, HUD icon, diagnostics (who has the mod, voice latency and loss, push-to-talk keys
  NightCoop also uses). English and Italian.
